# Ejercicios de React con Next.js

Guía de laboratorio

## Contenido

- **ejemplo 1/form-validation**: formulario con validación, componente reutilizable `TablaDatos`, barra de navegación y ruta `/conversor`.
- **ejemplo 2/currency-converter**: conversor de monedas.

## Tecnologías

- Next.js (App Router)
- React
- Bootstrap 5

## Cómo ejecutar un proyecto

```bash
cd "ejemplo 1/form-validation"
npm install
npm run dev
```

Abrir http://localhost:3000 en el navegador.
